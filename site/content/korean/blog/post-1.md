## 1. 활동 기간과 상태

- 기간: 2026.11.06 ~ 2026.11.07
- 상태: 진행 중

## 2. 활동 목적

개인 활동과 학습 내용을 정리하고
웹사이트를 통해 다른 사람에게 소개하는 것을 목표로 하였습니다.

## 3. 본인의 역할

이번 프로젝트는 개인 프로젝트로 진행하였습니다.

사이트 기획, 테마 선정, 설정 변경,
콘텐츠 작성, 배포 및 테스트를 ai의 도움을 받으며 직접 수행하였습니다.

## 4. 수행 과정

1. Hugoplate 테마 조사 및 선정
2. 프로젝트 구조 확인
3. Hugo 환경 설정
4. 자기소개 콘텐츠 작성
5. 메뉴와 페이지 수정
6. GitHub 저장소 연결
7. GitHub Pages 배포 및 검증

## 5. 도구와 선택 이유

Hugo를 선택한 이유는 정적 웹사이트를 생성할 수 있고
Markdown을 이용해 콘텐츠를 작성할 수 있기 때문입니다.

GitHub Pages를 사용한 이유는
GitHub 저장소와 연동하여 자동 배포를 구성할 수 있기 때문입니다

## 6. 배운 점

프로젝트를 진행하면서 웹사이트의 설정,
콘텐츠 구조, Git 버전 관리 및 자동 배포 과정을 학습하였습니다.

## 7. 개선 방향

앞으로 반응형 화면 구성과 접근성을 개선하고
추가적인 학습 활동을 웹사이트에 기록할 계획입니다.
